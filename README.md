# درع — بوابة الأمان الرقمي

واجهة عربية/إنجليزية مبنية بـHTML وCSS وJavaScript عادي، منشورة على Cloudflare Pages. المستودع يحتوي مجلدات مستقلة للموقع والعاملين: `site/`, `worker-ai/`, `worker-analysis/`, `worker-data/`.

## تدفق الخدمات

- **فحص الروابط:** واجهة Pages ترسل الطلب إلى Pages Function، ثم إلى `der3-security-analysis`. تستخدم الواجهة Cloudflare URL Scanner فقط. المسح عام ويتطلب موافقة صريحة، ويعرض حالة الفحص والتحويلات ورابط التقرير ولقطة الشاشة. عدم الاكتشاف لا يثبت الأمان. يدعم العامل أيضًا أوضاع `cloudflare`, `virustotal`, و`both` للاختبار، لكن لا تُشغّل أوضاع VirusTotal للعامة قبل ضبط حدود الاستخدام.
- **كشف الأخبار:** Pages Function تمرر الادعاء بعد موافقة المستخدم إلى `der3-ai` في وضع `news`. يستخدم العامل Cloudflare Workers AI بموديل `@cf/qwen/qwen3-30b-a3b-fp8` ويجري بحث Firecrawl إلزاميًا لإرفاق مصادر. لا تُعد النتيجة إثباتًا قاطعًا.
- **فحص الرسائل:** Pages Function تمرر النص بعد موافقة المستخدم إلى `der3-ai` في وضع `message`. التحليل نصي ولا يستخدم بحث الويب.
- **الشات التوعوي:** يتطلب checkbox موافقة قبل إرسال السؤال عبر Pages Function إلى وضع `chat` في عامل AI؛ قد يستدعي Firecrawl عند الحاجة إلى معلومات حديثة أو مصادر.
- **كلمات المرور المسرّبة:** فحص اختياري في المتصفح عبر HIBP بطريقة k-anonymity؛ لا تُرسل كلمة المرور أو التجزئة الكاملة.

توجد Pages Functions تحت `site/functions/`. لا تضع أي مفتاح في ملفات الواجهة أو Git. العاملان AI والتحليل يشترطان `API_KEY`، ويضيف Pages proxy السر المناسب في ترويسة `X-API-Key` من بيئة الخادم فقط. أسرار Pages للإنتاج: `DER3_AI_WORKER_API_KEY` و`DER3_ANALYSIS_WORKER_API_KEY`. أسرار الخدمات الأصلية تبقى في حسابات Workers المناسبة مثل `FIRECRAWL_API_KEY` و`CLOUDFLARE_URL_SCANNER_TOKEN` و`VIRUSTOTAL_API_KEY`.

## النشر

- Cloudflare Pages: مشروع `cyperaman-krm`، مجلد النشر `site/`، والفرع الإنتاجي `main`.
- Worker AI: الحساب `Al`؛ مجلد المصدر `worker-ai/`.
- Worker تحليل الروابط: حساب `Anlayzx` ذي المعرّف `c1d93f57cae70d680a28ceccbc88f638`؛ مجلد المصدر `worker-analysis/`.
- Worker البيانات: حساب `Datas`؛ عامل تمهيدي لا ينفذ حاليًا عمليات قراءة/كتابة.

`node dev-server.mjs` من جذر المستودع يخدم معاينة ثابتة فقط على `http://localhost:3000` ولا يشغّل مسارات `/api/*`. لاختبار الواجهة مع Pages Functions استخدم `npx wrangler pages dev site --port 8788` من جذر المستودع. ضع قيم `DER3_AI_WORKER_API_KEY` و`DER3_ANALYSIS_WORKER_API_KEY` محليًا في `.dev.vars` غير المتعقب؛ لا تضع الأسرار في الأمر أو ملفات الواجهة. Pages Functions تُنشر مع الموقع من مجلد `site/`.

## تحقق الإنتاج

في 2026-10-22، اختُبرت واجهة الإنتاج بعد دمج `a0db7a7`: اكتمل فحص رابط موقع درع عبر Cloudflare URL Scanner (`not_detected`، وليس ضمانًا للأمان)، وظهر التقرير وأعاد Pages proxy لقطة `image/png`. اختُبرت أدوات الأخبار والرسائل والشات من الواجهة، وأعاد كل منها إجابة فعلية؛ اختبار خبر تاريخي أظهر أن البحث يعمل لكنه أدرج أيضًا مصادر اجتماعية، لذا النتائج إرشادية وتتطلب مراجعة المصدر.

بعد دمج PR #8 (`5499998`) تحققت الواجهة الحية بالعربية والإنجليزية: موافقة الأخبار تذكر Workers AI وFirecrawl، وإفصاح الرسائل لا يذكر البحث، وترحيب الشات يصف المساعد بأنه متصل بالذكاء الاصطناعي. بعد دمج PR #9 (`f98341b`) أكّد المتصفح أن أصول الإنتاج تتضمن رسائل 429/503 المترجمة بالعربية والإنجليزية. لم يُنفذ اختبار ضغط أو استدعاء مصطنع لإجبار الخدمة على تجاوز الحد.

لا يكتب الكود نصوص الروابط أو الرسائل أو الأخبار أو المحادثة في سجل النشاط؛ تُحفظ ملخصات عامة فقط. روابط Cloudflare تمسحها خدمة خارجية وتنتج تقارير عامة. النصوص التي يختار المستخدم إرسالها إلى AI أو Firecrawl يعالجها المزود وفق شروطه، لذا لا تُدخل بيانات شخصية أو كلمات مرور أو رموز OTP.

## غير موصول حاليًا

- **البحث الآمن:** يعرض أمثلة محلية؛ لم يظهر في `bardy.pages.dev` API موثق يمكن ربطه بأمان.
- **البحث عن أرقام الهواتف:** مؤجل كما طلب المستخدم؛ النموذج الحالي إرشادي محلي.
- **عامل البيانات `der3-data-api`:** نقطة `/health` فقط، وبقية المسارات تعيد `501`. لا توجد جداول أو مصادقة أو عمليات جمع بيانات؛ لم نربطه بتسجيل الدخول.
